# Automated Sales Report

Projeto de portfólio para automatizar a análise de dados sintéticos de vendas e gerar relatórios profissionais em Excel.

## Estrutura

- `data/raw/`: arquivos CSV de entrada.
- `output/`: relatórios gerados.
- `src/`: código-fonte da aplicação.
- `tests/`: testes do projeto.

A aplicação será desenvolvida em Python. A implementação será adicionada nas próximas etapas.
